# pwgen.py

パスフレーズと「コード」から、決定的(同じ入力なら常に同じ結果)なパスワードを生成するツールです。パスワード自体は保存せず、必要なときに毎回同じ入力から再生成する使い方を想定しています。

## 使い方

```
python pwgen.py [PASSPHRASE CODE]
```

引数を省略すると、対話的に入力を求めます。

```
passphrase: ********
code: 000001s-32
```

### 引数

- `PASSPHRASE` : パスワード生成の元になる秘密の文字列
- `CODE` : 生成条件を表すコード。形式は `NNNNNN[s][-LEN]`
  - `NNNNNN` : 6桁の数字(サイト名やアカウントごとの識別番号など、覚えやすい/区別できる値を自由に決める)
  - `s` : 付けると記号 (`!#$%*+-=?@_`) をパスワードに含める(省略可)
  - `-LEN` : パスワードの長さ(8〜32、省略時は16)

同じ `PASSPHRASE` と `CODE` の組み合わせからは、常に同じパスワードが生成されます。`CODE` を変える(例: 数字部分やLENを変える)ことで、同じパスフレーズから用途ごとに異なるパスワードを作り分けられます。

### オプション

- `-h`, `--help` : 使い方を表示して終了
- `-v`, `--version` : バージョン情報を表示して終了

## 出力

```
password: -rcj#C8Z5vf3Za*3LadNnL-NyK@cTZXk  check: 🐘🐠
```

- `password` : 生成されたパスワード
- `check` : チェックコード(絵文字2つ)。`PASSPHRASE` のみから導出した鍵の確認用コードで、`CODE` には依存しません。同じパスフレーズなら常に同じ絵文字になるため、パスフレーズの入力間違いに気付く手がかりとして使えます。

## 仕組み

- `PASSPHRASE` から PBKDF2-HMAC-SHA256(60万回イテレーション)で鍵を導出します。
- その鍵と `CODE` を使って HMAC-SHA256 ベースでパスワード文字を生成します(数字・大文字・小文字・記号の見分けにくい文字 `0 O 1 l I` などは除外)。
- 生成されたパスワードは、数字・大文字・小文字(`s` 指定時は記号も)を少なくとも1文字ずつ含むことを保証します。
- パスフレーズとコードが同じであれば、いつ実行しても同じパスワードが得られます。
